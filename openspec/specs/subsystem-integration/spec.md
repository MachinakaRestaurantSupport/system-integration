# subsystem-integration Specification

## Purpose
全体システム設計で定義された連携ポイント I-1〜I-6 を通じて、8つのサブシステムが疎結合にデータ連携し、店舗業務のE2Eシナリオを完結できることを定義する。

## Requirements

### Requirement: 注文生成から注文管理への連携（I-1, I-2, I-5）
**USDM**: R03-01
店内注文および持ち帰り注文サブシステムは、メニュー管理から公開メニューを参照し（I-5）、確定した注文を注文管理サブシステムへ連携（I-1, I-2）しなければならない（SHALL）。

#### Scenario: 店内QR注文から注文管理への登録
- **WHEN** 店内注文サブシステムが席QRトークンに紐づくメニュー注文を確定する
- **THEN** 注文管理サブシステムに店内注文が登録され、かんばんステータスが受付済みとなる

#### Scenario: 持ち帰り事前注文から注文管理への登録
- **WHEN** 持ち帰り注文サブシステムがSNS認証済み顧客の受取予約注文を確定する
- **THEN** 注文管理サブシステムに持ち帰り注文が登録され、注文状況確認が可能となる

### Requirement: 会計完了と席状態・売上集計への連携（I-3, I-4, I-6）
**USDM**: R03-01
会計管理サブシステムは注文管理から会計金額を取得して決済を完了し（I-3）、顧客管理の席状態更新（I-6）および売上管理への売上データ供給（I-4）を連携しなければならない（SHALL）。

#### Scenario: 店内会計完了後の席解放と売上計上
- **WHEN** 注文管理の注文に対して会計管理で決済を完了する
- **THEN** 顧客管理の座席ステータスが清掃中（または再案内可能）へ更新され、売上管理に売上レコードが計上される
